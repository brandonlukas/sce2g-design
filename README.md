# sce2g-design

Figure design system measured from the main figures of Sheth, Qiu et al., "Mapping enhancer–gene
regulatory interactions from single-cell data", *Nature Genetics* (2026),
[doi:10.1038/s41588-026-02695-8](https://doi.org/10.1038/s41588-026-02695-8). Rules and tokens are in
[`DESIGN_SYSTEM.md`](DESIGN_SYSTEM.md) and `tokens.json`; `figures/` re-draws the paper's panels from
digitised data; `.claude/skills/sce2g-figures` packages it as a Claude skill.

`refs/sce2g-2026.pdf` is the unmodified article, © The Author(s) 2026, redistributed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); the digitised data and re-drawn panels are
adapted from it.
